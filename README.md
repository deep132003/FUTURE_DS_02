# 📊 Digital Marketing Ads Performance Dashboard (Power BI)

## 📌 Project Overview
This Power BI dashboard analyzes digital advertising campaign performance across multiple platforms, devices, audience demographics, and ad categories.  
It helps track key marketing KPIs like impressions, clicks, CTR, conversion rate, engagement, and user interest trends.

---

## 🎯 Objectives
- Monitor overall campaign performance using marketing KPIs
- Compare performance across platforms (Instagram vs Facebook)
- Identify best-performing audience groups (age & gender)
- Analyze device-wise engagement and impressions
- Understand weekly trends in clicks and impressions
- Find top ad categories and user interest areas

---

## 🛠 Tools & Technologies Used
- Power BI
- Power Query (Data Cleaning & Transformation)
- DAX Measures (KPIs & Calculations)

---

## 📈 Key KPIs Included
- **Total Clicks**
- **Total Impressions**
- **CTR (Click Through Rate)**
- **Conversion Rate**
- **Total Conversions**
- **Average Time Spent**
- **Average Engagement Score**

---

## 📊 Dashboard Features & Visuals
- **Platform Performance** (CTR, Conversion Rate, Engagement Score)
- **Age-based Performance** (Clicks by age group)
- **Gender-based Performance** (Donut chart)
- **Day of Week Performance** (Clicks & impressions trend)
- **Device Type Performance** (Mobile, Tablet, Desktop)
- **Ad Type Performance** (Image, Video, Carousel)
- **Impressions by Ad Category** (Treemap)
- **User Interest Analysis** (Engagement score by interest)
- Interactive **Slicers** for filtering by:
  - Platform
  - Gender
  - Age
  - Day of Week
  - Device Type

---

## 🔍 Key Insights (Summary)
- Platform performance differs significantly across Instagram and Facebook
- Engagement varies based on ad type (Image/Video/Carousel)
- Certain ad categories generate higher impressions (ex: Electronics, Gadgets)
- Weekdays show different traffic patterns for clicks and impressions
- User interests like **Travel / Tech / Food** show high engagement
